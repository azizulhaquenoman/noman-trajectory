ASSET PLACEMENT GUIDE
=====================

1. profile.jpg
   → Your profile photo (square crop recommended)
   → Used in: About section + browser favicon

2. resume.pdf (place in public/assets/)
   → Your CV/Resume PDF
   → Opens in new tab when Resume button is clicked

3. projects/ folder — add these thumbnails (any resolution, 16:9 ratio works best):
   directedge.jpg   → DirectEdge supply chain platform
   kairos.jpg       → Kairos personal growth platform
   cookcorner.jpg   → Cook Corner smart cooking app
   healthcare.jpg   → UIU Health Care Management system
   codecampus.jpg   → codeCAMPUSTrail desktop app
   autotrack.jpg    → AutoTrack research paper

4. projects/ folder — optional gallery images (3 per project):
   directedge-1.jpg, directedge-2.jpg, directedge-3.jpg
   kairos-1.jpg,     kairos-2.jpg,     kairos-3.jpg
   cookcorner-1.jpg, cookcorner-2.jpg, cookcorner-3.jpg
   healthcare-1.jpg, healthcare-2.jpg, healthcare-3.jpg
   codecampus-1.jpg, codecampus-2.jpg, codecampus-3.jpg
   autotrack-1.jpg,  autotrack-2.jpg,  autotrack-3.jpg

NOTE: If any image is missing, a themed fallback illustration
      is shown automatically — the site still looks great!
